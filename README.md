# CMU ML Research

One-page site for the Carnegie Mellon University ML Research collective.

Live: [aarushkandukoori.github.io/cmu-ml-research](https://aarushkandukoori.github.io/cmu-ml-research/)

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

## Interest form

The join form posts to [FormSubmit](https://formsubmit.co/) and emails `akanduko@andrew.cmu.edu`. The first submission may require a one-time inbox confirmation.
